# 0493x6f2 — bounded phase geometry before interface filtering

## Purpose

The x6c resident `rawFill` is a normalized liquid mass/occupancy field,

    raw[c] = sum_s(liquid) M_s[c] / sum_s(liquid) M_ref,s

and is intentionally allowed to exceed one. Long x6f dam-break diagnostics showed
that interpreting this unbounded occupancy field directly as geometry can create a
false liquid interface in an empty cell. With lambda=0.125, one neighbour with
raw=4.1 can give an empty cell alpha=0.5125.

0493x6f2 separates occupancy from geometry without adding a resident field or a
production CUDA pass.

## Geometry reinterpretation

`phaseFillRaw0493x6c` is unchanged and remains the unbounded occupancy diagnostic.
The geometric source used by the existing five-point filter is now

    geom0[c] = clamp(raw[c], 0, 1)

and

    alpha[c] = geom0[c]
             + lambda * sum_face_neighbours(geom0[nb] - geom0[c])

with the existing lambda=0.125 and no-flux convention at missing non-periodic
neighbours. Because 0<=geom0<=1 and lambda<=1/4, the update is a convex
combination and alpha remains in [0,1] without a post-filter clip.

The demonstrated empty-cell counterexample becomes alpha=0.125 rather than
0.5125 when its only contributing neighbour has raw=4.1.

## Scope

The patch changes only the interpretation of resident phase geometry consumed by
x6d/x6e/x6f/x6g. It does not change the raw liquid mass deposit, carrier criterion,
x6f pressure-mask definition, x6g gas-pressure construction, SRC, force ordering,
streaming, thermostat, boundary conditions, Darcy/chi or resampling. No new user
parameter or environment flag is introduced.

## Audit semantics

`cuda_phase_geometry_resident_0493x6c.csv` keeps `rawFillSum` and adds
`boundedGeometrySourceSum` and `boundedGeometryClippedCells`.
`conservationRelativeError` now compares the filtered field with the bounded
geometric source; `filterDeltaRms` measures alpha-geom0. The failure-only x6f-d3
reconstruction applies the same clamp while still printing the original raw values.

## Intended qualification

Rebuild the CUDA binary, then test x6f without resampling at
`speciesQ6MinOccupancyFraction=0.10`. The decisive run is the 300x150 gamma=10
dam-break through at least 1600 steps. If an incompatible component remains,
d1/d2/d3 can now distinguish a genuine carrier-support hole from the false
geometry previously generated by unbounded occupancy smoothing.
