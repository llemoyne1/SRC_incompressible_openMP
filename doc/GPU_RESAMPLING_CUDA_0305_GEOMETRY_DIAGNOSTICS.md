# 0305 — Boundary-classified CUDA support diagnostics

This patch extends the passive post-SRC/post-thermostat adaptive flag diagnostic
introduced in 0304.  It still does not mutate particles and does not trigger an
adaptive guard.  Its purpose is to identify where empty or low-population cells
occur relative to the geometry:

- bulk fluid cells;
- wall-adjacent cells;
- immersed-solid-adjacent cells;
- open-boundary-adjacent cells;
- corner-like cells, identified by at least two blocked neighbouring directions.

The motivation is that empty cells observed in backward-step and wake demos may
not be a bulk-fluid support failure.  They can be concentrated in wall/cut/corner
regions where advection is constrained by impermeable boundaries and where
cell-averaged velocity diagnostics are easily polluted by one or two particles.

## Placement

The diagnostic is evaluated after the SRC classic CUDA step and thermostat, on
the physical non-shifted grid, at the same insertion point as the current
post-SRC resampling modules.  This keeps the diagnostic tied to the state that
would be given to the population guard/refill modules.

The class counters are intentionally non-exclusive except `bulk`, which means an
active fluid cell not adjacent to wall, open boundary, immersed solid, or a
corner-like blocked configuration.

## Scripts

The main sweep script is:

```bash
scripts/run_cuda_resampling_geometry_diagnostics_0305.sh
```

It runs light-grid diagnostics for:

- backward step;
- Von Karman circle + inlet/outlet;
- Poiseuille wall channel;
- Taylor-Green periodic with an initial empty bulk hole.

The Taylor-Green hole case is generated by:

```bash
scripts/run_demo_src_resampling_cuda_taylor_green_hole_0305.sh
```

It starts from a periodic Taylor-Green state and converts particles in a small
central rectangle to `Inactive`, leaving the cells fluid.  This is intended to
check whether a bulk support hole is naturally filled by advection and whether
the guard smooths the resulting population heterogeneity.

## Interpretation

The expected questions are:

1. Are empty cells mostly bulk cells or wall/solid/corner-adjacent cells?
2. Are the very large apparent velocities localized in low-mass wall/cut/corner
   cells?
3. Does the Taylor-Green bulk hole disappear under advection/resampling?
4. Should the next correction be an adaptive scheduler, a wall-aware threshold,
   a last-valid cache, or a true empty-cell refill?

This patch deliberately answers only the diagnostic part.  It does not introduce
last-valid cell fields or a refill mechanism.
