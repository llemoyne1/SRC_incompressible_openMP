# 0066 — Open-boundary backward-step validation

This case extends the inlet/outlet sequence from clean open-channel/Poiseuille
runs to a static backward-facing step represented by the existing bottom-attached
immersed rectangle:

```text
bcLeft   = inlet
bcRight  = outlet
bcBottom = solid
bcTop    = solid
immersedSolidShape = rectangle
immersedSolidXMin/XMax = 0.25 / 0.65
immersedSolidYMin/YMax = 0.0 / 0.50
```

The patch deliberately keeps the scope narrow.  It enables Q6/Q9/virial
inlet/outlet only for a **static immersed rectangle** with
`projectionImmersedSolidMaskEnable=true`.  Moving immersed solids and the circle
remain separate validations, because the cylinder still has a known strict Q6
cell-closed leak diagnostic.

## Numerical policy

The particle inlet/outlet is the 0061b CUDA-like recycle path.  Q6 and Q9 keep
the 0062/0063 balanced open-flux elliptic boundary conditions.  The virial kick
uses the 0064 bulk-only policy: inlet/outlet reservoir cells are excluded from
virial diagnostics and kicks.

The default validation script launches three cases:

```text
backstep_q6_keepmean_s050
backstep_q9_keepmean_b0001
backstep_q9_virial_keepmean_K0p50_b0p05_ex3
```

The run is still a controlled short-domain validation: `keepMeanFlowEnable=true`
is enabled by default to exercise the outlet without waiting for a long
convective time.  This makes the case suitable as a regression and structural
comparison before attempting longer no-keepMean runs.

## Run

From repository root:

```bash
./scripts/run_backward_step_open_channel_validation_0066.sh
```

Useful options:

```bash
CASE_STEPS=1000 ./scripts/run_backward_step_open_channel_validation_0066.sh
CASE_STEPS=6000 NUM_THREADS=8 ./scripts/run_backward_step_open_channel_validation_0066.sh
RUN_CLASSIC=1 ./scripts/run_backward_step_open_channel_validation_0066.sh
RUN_NO_KEEPMEAN=1 ./scripts/run_backward_step_open_channel_validation_0066.sh
```

The default initial state is generated by:

```matlab
cd matlab
generate_backward_step_state('output','../initial_state_backward_step_96x48_g20.smpcd');
cd ..
```

## Analysis

```matlab
cd matlab
suite = analyze_backward_step_open_channel_validation_0066('root','..');
cd ..
```

The analysis reuses the mature backward-step structure diagnostics and writes:

```text
runs/backward_step_open_channel_validation_0066_analysis/backward_step_open_channel_validation_0066_summary.csv
runs/backward_step_open_channel_validation_0066_analysis/backward_step_open_channel_validation_0066_lower_profiles.csv
```

Primary checks:

```text
Np/mass conserved in runtime summaries
Q6/Q9 converged
Q6/Q9 immersed-solid leak diagnostics finite and monitored
virial kick applied, du/thermal small, momentum residual after correction ≈ 0
population low-tail in the downstream/reversed region not worse than Q6/Q9 baseline
reversed region present and coherent behind the step
```
