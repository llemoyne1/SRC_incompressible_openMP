# 0493x7n — path-selectable fluid calibrator

## Purpose

0493w1 characterizes the underlying SRC fluid with Q6 and resampling disabled.
That remains a useful baseline, but it is not sufficient when a production
simulation uses a projected or otherwise modified numerical path.

0493x7n keeps the 0493w1 experiments, state generation, sampling and analyzer,
while making the integration path explicit:

    CALIBRATION_PATH=src
    CALIBRATION_PATH=src-q6
    CALIBRATION_PATH=src-q6-g-f

Any path accepted by `suite_validate_path_0434` is accepted by the runner.
`src` remains the default. The original
`scripts/run_0493w1_src_fluid_calibrator.sh` is not modified.

## Path authority

The selected path is passed through the existing 0434/x7h common helpers:

- `suite_write_common_params_0434`
- `suite_export_cuda_flags_0434`

Therefore projection enablement, resampling enablement, resident CUDA flags and
the Q6-g-f parameter block come from the same path-selection code as run_ok
simulations.

For single-phase Q6-g-f calibration, the autogenerated liquid registry inherits
`PARTICLE_MASS` through `Q6_GF_SINGLE_PHASE_PARTICLE_MASS`.

Q6-g-f controls remain ordinary environment overrides, e.g.

    Q6_GF_DENSITY_RELAXATION_TIME=0.25
    PROJECTION_TOLERANCE=1e-5
    PROJECTION_MAX_ITERATIONS=800

This permits controlled ablations such as `tau_rho=0` without another
calibrator.

## Observable interpretation

### Taylor–Green transverse viscosity

Applicable to every path. It measures transverse momentum transport under the
complete selected numerical path.

### Periodic MSD / self diffusion

Applicable to every path. Together with TG viscosity it defines the effective
Schmidt number of the selected path.

### Acoustic experiment

For an unprojected SRC path it retains the 0493w1 interpretation as a
sound-speed and longitudinal-attenuation calibration.

For a Q6 path, ordinary sound speed is not applicable: projection deliberately
suppresses or modifies longitudinal compressive modes. The acoustic experiment
is retained only as a diagnostic of residual longitudinal response.

The historical 0493w1 analysis outputs are preserved for compatibility.
0493x7n additionally writes

    analysis/calibration_path_0493x7n.json

which records the path and observable applicability so a projected-path run
cannot silently be mistaken for an ordinary SRC acoustic calibration.

## Recommended comparison for the current Poiseuille investigation

Use the production local signature:

    gamma = 20
    dt = 0.001
    kBT = 0.001
    particle mass = 1
    rotation angle = 1.5
    random rotation sign = true
    grid shift = true
    thermostat = cell_relative_rescale, every step

Compare at least:

1. `CALIBRATION_PATH=src`
2. `CALIBRATION_PATH=src-q6`
3. `CALIBRATION_PATH=src-q6-g-f`, `Q6_GF_DENSITY_RELAXATION_TIME=0.25`
4. `CALIBRATION_PATH=src-q6-g-f`, `Q6_GF_DENSITY_RELAXATION_TIME=0`

The first decisive observable is TG viscosity. If Q6-g-f preserves TG
viscosity while Poiseuille changes strongly, the defect is associated with
forcing/wall coupling rather than intrinsic transverse momentum transport.


## fix1 — path-aware authoritative preflight

The initial x7n execution path was already routed through the production common
helpers, but the inherited 0493w1 preflight still printed hard-coded
`q6=false resampling=false`.

fix1 makes the descriptive preflight path-aware and renders the actual common
parameter block for `CALIBRATION_PATH`. It checks the effective last values of
projection/resampling and, for Q6-g-f, verifies `prestream_single_fused`,
disabled global momentum correction, the one-phase registry and
`free_surface_masked`. It also prints x6c/x6f/B1 CUDA flags. No simulation is
launched in `PREFLIGHT_ONLY=1`.


## fix2 — projection solver settings belong to the calibrated path

The original 0493w1 runner hard-coded

    PROJECTION_MAX_ITERATIONS=100
    PROJECTION_TOLERANCE=1e-12

which was harmless while the calibrator was SRC-only because projection was
disabled. Once Q6 paths are calibrated, these values become part of the
numerical-path definition and must be selectable by the caller.

fix2 preserves the historical defaults but makes them ordinary environment
overrides:

    PROJECTION_MAX_ITERATIONS="${PROJECTION_MAX_ITERATIONS:-100}"
    PROJECTION_TOLERANCE="${PROJECTION_TOLERANCE:-1e-12}"

A Q6 calibration can therefore use the same solver contract as production,
for example:

    PROJECTION_MAX_ITERATIONS=800
    PROJECTION_TOLERANCE=1e-5


## fix3 — selectable calibration experiments

The calibrator can now execute a selected subset of experiment families:

    CALIBRATION_EXPERIMENTS="tg"
    CALIBRATION_EXPERIMENTS="msd"
    CALIBRATION_EXPERIMENTS="tg msd"
    CALIBRATION_EXPERIMENTS="tg sound msd"

The default is `tg sound msd`, preserving the complete historical 0493w1
behavior.

State generation and simulation are conditional, so a TG-only transport test
does not generate or run sound/MSD cases.

The historical `analyze_0493w1_src_fluid_calibrator.py` is called only when all
three experiment families are present.  For a partial campaign the runner
writes `analysis/PARTIAL_ANALYSIS_0493x7n.txt` and does not synthesize missing
observables.  A dedicated TG-only analyzer is intentionally handled as a
separate follow-up so the complete 0493w1 analysis contract is not weakened.

The path manifest records the selected experiment list.


## fix4 — canonical TG-only analysis

Partial campaigns containing `tg` are now analyzed without duplicating the
0493w1 viscosity algorithm.

`scripts/analyze_0493x7n_tg_only.py` imports
`analyze_0493w1_src_fluid_calibrator.py`, delegates argument parsing to its
canonical `parse_args()`, and calls its canonical `analyze_tg(a)`.

It therefore inherits the same particle-state reader, TG modal amplitude,
automatic fit-window selection, `nu=-slope/k^2` convention, fit R2, window
spread/min/max, and PASS/REVIEW/INVALID viscosity thresholds.

TG-only outputs:

    analysis/tg_decay_0493w1.csv
    analysis/tg_calibration_0493x7n.json
    analysis/tg_calibration_0493x7n.csv

The x7n summary also records path, x7d tau, projection tolerance/max iterations
and the local fluid signature.

The complete historical analyzer remains unchanged and is still used whenever
`CALIBRATION_EXPERIMENTS` contains all of `tg sound msd`.


## fix4b — active-path metadata

The TG-only summary now distinguishes configured values from active path
physics. `q6DensityRelaxationTime` is published only for Q6-g-f paths and is
`null` for SRC / legacy Q6 calibrations.

The canonical 0493w1 TG API was observed to expose `fitStartIndex` and
`fitEndIndex`; these are now recorded directly, without converting them into
unverified step numbers.


## fix4c — TG low-linearity robustness

The canonical 0493w1 TG analyzer had an uncovered case: candidate decay
windows can exist while none reaches the strict `R2 >= 0.97` stable-window
floor. In that case `stable` is empty and the historical code crashed while
computing `min/max(nus)`.

The strict definition of a stable window is preserved. New diagnostics are:

    fitStableWindows
    fitStableFallback

When `fitStableWindows == 0`, the already-selected best candidate `chosen` is
used only for viscosity-window range statistics. Fit selection and the
PASS/REVIEW/INVALID R2 thresholds are unchanged.
