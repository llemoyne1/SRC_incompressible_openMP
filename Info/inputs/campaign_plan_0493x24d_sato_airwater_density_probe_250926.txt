NUMERICAL ACCOMMODATION REQUIRED BY CURRENT CODE
-------------------------------------------------
A literal mass-only change at dt=1e-3 and kBT_G=0.08 violates the existing
resolved-flight guard because both thermal and driven gas particle flights become
too large when m_G is reduced by ~85x.

Therefore x24d uses the minimal explicit numerical accommodation:
  m_L      = 1
  m_G      = 1.17/997 = 0.0011735205616850552
  kBT_L    = 0.02
  kBT_G    = 0.0009388164493480442
  kBT_G/m_G = 0.8, identical to x24b (0.08/0.1)
  dt       = 0.0004

For target Fr_m'=0.660364520158346, this gives approximately:
  U_jet                 = 5.9694820421 (simulation units)
  C_thermal             = 0.09159 cell/step
  C_jet                 = 0.61127 cell/step
  C_thermal + C_jet     = 0.70286 < 0.80 current guard

Gravity and surface tension remain at the x24b values so that the already matched
Bond number is preserved.  This probe therefore changes density ratio plus only
what is numerically required to resolve that change; it does not yet attempt to
match Re_L, Re_G or Oh_L.
