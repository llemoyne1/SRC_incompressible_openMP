# 0493x9l — wall-face contact-angle normal closure

Incremental experiment on top of **0493x9k**.

## Motivation

x9i imposed the prescribed Young angle directly on the first cell-centred normal: the angle was exact but `div(n)` saw a discontinuity and the contact curvature was badly biased. x9j moved the condition to ghost alpha and improved some angles, but did not preserve multi-layer curvature geometry. x9k used a sheared mirror of alpha; it imposed angle robustly but an affine shear does not preserve a circle, so curvature remained strongly angle-dependent.

x9l leaves both physical `alpha_x6c` **and** the p3 curvature alpha field unchanged. It moves the closure to the quantity used by the curvature operator: the unit-normal field.

## Wall-face construction

For a static domain wall, let

- `n_w` be x9h's fluid-to-solid wall normal;
- `n_face` be the prescribed A-to-B interface normal at the physical wall face, with `n_face . n_w = -cos(theta)`;
- `n2` be the unmodified p3 normal one cell farther into the fluid, at normal coordinate `s=3h/2`.

The signed angle from `n_face` to `n2` is `DeltaPhi`. x9l reconstructs

- first fluid cell centre (`s=h/2`): `phi0 = phi_face + DeltaPhi/3`;
- first ghost centre (`s=-h/2`): `phi_g = phi_face - DeltaPhi/3`.

Both vectors are generated by rotation, hence remain exactly unit length. The normalized average of first-cell and ghost normals therefore has the exact wall-face angle. The Scharr `div(n)` stencil consumes these normals directly; alpha is never sheared or extrapolated.

## Scope

- `0 < theta < 180` only. Exact complete-wetting/dewetting endpoints remain deliberately unsupported.
- Static domain walls only for this qualification.
- `chi`/wallVP wall geometry is still available through x9h, but x9l refuses mixed/chi-only contact-angle closure until the domain-wall formulation is qualified.
- No new persistent simulation parameter is added. The experimental path is selected by
  `MPCD_Q6_CONTACT_ANGLE_WALL_FACE_0493X9L=1` in the x9l runner.
- `surfaceTensionSigma`, x6c/x6f/x6g, CG and B1 are unchanged.

## Apply

From repository root:

```bash
python3 x9l_bundle/tools/apply_0493x9l_wallface_normal.py
```

The installer is semantic-anchor based, idempotent, and has no Git working-tree guard. It also works if copied to `tools/` while the extracted `x9l_bundle/` remains in the repository root.

## Static checks and build

```bash
git diff --check -- . ':(exclude)livevis_control.kv'

bash -n scripts/run_0493x9l_contact_angle_wallface.sh
python3 -m py_compile \
  scripts/analyze_0493x9l_contact_angle_wallface.py \

python3 scripts/check_0493x9l_wallface_geometry.py

bash scripts/build_src_mpcd_cuda_q6_resident_livevis_0486.sh
```

The mapcheck covers 30,45,...,150 degrees and verifies exact face-angle reconstruction and unit-normal preservation.

## Qualification campaign

Preflight:

```bash
PREFLIGHT_ONLY=1 \
LIVE_VIS_ENABLE=0 \
LIVE_PROGRESS=1 \
bash scripts/run_0493x9l_contact_angle_wallface.sh
```

Then the full one-step geometric sweep:

```bash
LIVE_VIS_ENABLE=1 \
LIVE_VIS_HOLD_ON_EXIT=0 \
LIVE_PROGRESS=1 \
FILTERED_RECORDING_ENABLE=0 \
bash scripts/run_0493x9l_contact_angle_wallface.sh
```

Default angles are

`30 45 60 75 90 105 120 135 150`.

For each angle the hard gates are:

- nonzero candidates and all candidates reconstructed;
- mean wall-face angle within 2 degrees and angle RMS error <= 3 degrees;
- `|kappa_contact - 1/R| / (1/R) <= 10%`.

Curvature standard deviation is reported but is not yet a hard gate in this first x9l experiment. Existing x9k runs are used as an optional baseline when present.
