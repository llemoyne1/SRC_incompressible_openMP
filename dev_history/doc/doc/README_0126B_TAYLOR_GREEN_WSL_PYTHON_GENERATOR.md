# 0126B — Taylor--Green generator without MATLAB on WSL

This corrective patch removes the hard MATLAB dependency from the 0126 Taylor--Green launcher.

## Why

On Ubuntu/WSL, MATLAB may not be available in `PATH`.  The original 0126 launcher stopped before creating the three run directories:

```text
runs/taylor_green_resampling_0126/classic
runs/taylor_green_resampling_0126/q6
runs/taylor_green_resampling_0126/q6_resampling
```

because the initial `.smpcd` state was generated by MATLAB.

## Change

The launcher now supports:

```bash
TG_GENERATOR=auto    # default: python3 first, then MATLAB
TG_GENERATOR=python  # force the Python generator
TG_GENERATOR=matlab  # force the MATLAB generator
RUN_ANALYSIS=auto    # default: run MATLAB analysis only if MATLAB is found
```

The new generator is:

```text
scripts/generate_taylor_green_resampling_state_0126.py
```

It writes a V2 `.smpcd` state with `role=Fluid` for all particles and needs only the Python standard library.

## WSL usage

```bash
cd /mnt/e/SRC_MPCD_dev/SRC_openMP_resampling
rm -rf runs/taylor_green_resampling_0126

TG_GENERATOR=python \
RUN_ANALYSIS=auto \
TG_NX=32 TG_NY=32 TG_GAMMA=20 \
TG_STEPS=200 TG_DUMP_EVERY=50 TG_THREADS=4 \
./scripts/run_taylor_green_resampling_validation_0126.sh
```

If MATLAB is unavailable, the OpenMP runs still complete and analysis is skipped.  Later, from MATLAB, run:

```matlab
cd('/mnt/e/SRC_MPCD_dev/SRC_openMP_resampling')
addpath('matlab')
analyze_taylor_green_resampling_0126('runs/taylor_green_resampling_0126','makePlots',true)
```
