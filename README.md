# 0435c Level-B concise validation helpers

Copy the scripts into `scripts/` from the repository root:

```bash
cp summarize_0435c_levelB.py scripts/
cp run_levelB_summary_0435c.sh scripts/
chmod +x scripts/summarize_0435c_levelB.py scripts/run_levelB_summary_0435c.sh
```

Then run:

```bash
bash scripts/run_levelB_summary_0435c.sh
```

The output is concise and is also written to:

```text
runs/0435c_levelB_summary.txt
```

You can pass custom output directories as arguments if needed.
